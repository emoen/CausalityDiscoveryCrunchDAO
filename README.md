### Causal Discovery observations:

-Comprehensive Review and Empirical Evaluation of Causal Discovery Algorithms for Numerical Data
https://arxiv.org/html/2407.13054v1
<code>
1. For the linear dataset, CCM
2. Across other datasets, the PAI algorithm consistently emerges as the pinnacle performer particular nonlinear and Gaussian datasets: (L>300)
3. For systems sensitive to false causality, preference should be given to the FPR metric. 
4. In cases involving linear interrelationships among variables, ANM is the preferred choice
5. When dealing with nonlinear relationships among variables, the PAI algorithm emerges as the optimal selection.
</code>
